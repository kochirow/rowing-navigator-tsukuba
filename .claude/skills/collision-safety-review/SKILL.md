# 衝突警告 安全レビュー(false negative 監査)

## 目的と判断基準

このアプリは漕手の背後方向の視界を補う衝突警告システムであり、**「鳴らなかった警告」が事故に直結する**。
警告漏れに加え、継続的な誤報による警告の形骸化も安全機能の喪失として扱う。
したがってこのレビューでは一貫して次の基準で判断する:

- 迷ったら「指摘する側」に倒す。無根拠のOKは禁止。
- fail-silent(失敗を握りつぶして「脅威なし」を返す)は、それ自体を欠陥として扱う。
- FN/FPの交換条件は運用前提と実際の影響で評価する。重大度は `docs/review_guide/README.md` §3.3を正本とし、形骸化する誤報もS1になり得る。

## モード

- **差分監査（対象変更が指定されている場合）**：変更点から入力・評価・提示への影響経路、対応する不変条件、境界条件を追う。[監査観点](references/audit-checklist.md)のA〜Hとシナリオから関連項目を選び、根拠と検証を記録する。影響が不明な箇所は調査を広げる。
- **総合監査（明示的な全体安全監査、または総合レビューP05）**：[総合監査手順](references/audit-checklist.md)の標準セット・全項目・全シナリオを適用する。

差分監査は、依頼範囲と影響経路の判定・根拠、必要な関連検証、所見と未確認範囲を報告したら完了。全体安全性を確認済みとはしない。報告の保存は依頼または親レビューの出力先に従い、同じ報告を重複作成しない。
