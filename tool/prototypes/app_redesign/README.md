# 画面刷新 試作（HTML）

記録画面(リプレイ)で決めた見た目を、ほかの画面へ広げるための試作。
**アプリのコードではない。** 利用者と操作しながら仕様を決めるための参照物として残す。
経緯・判断・未決事項は [docs/design_notes/2026-09-25_画面刷新_試作v1.md](../../../docs/design_notes/2026-09-25_画面刷新_試作v1.md)。

## 開き方

```bash
python3 -m http.server 8766 --directory tool/prototypes/app_redesign
```

ブラウザで `http://localhost:8766/` を開く。PCでは端末の枠と説明が並び、
スマホの幅(460px未満)では端末が全幅になる。

- 上の操作バーで画面(①出艇前 ②航行中 ③記録一覧 ④警告の設定)と暗色/明色を切り替える。
- 画面ごとに「シナリオ」(警告の段階、GPSが弱い、音量が小さい など)を切り替えられる。
- 地図は簡略化した絵で、実際の地図ではない。数値はすべてダミー。外部通信はフォントの読み込みだけ。
