# 2026-07-31 橋脚の外周ポリゴン方式への変更

## 目的

橋脚の作図方法を、長辺2点と実測幅から矩形を生成する方式から、航空写真上で橋脚の実際の外周を直接囲む方式へ変更した。

## 変更内容

- プロットツール
  - 橋脚の種別名を「橋脚（外周ポリゴン）」へ変更。
  - Inspector の幅[m]入力、先頭2点からの矩形化、外接寸法表示、これらを前提にした説明を削除。
  - 「橋脚の実際の外周を3点以上で直接囲む」説明を表示。
  - 検証エラーの文言を「3点以上の外周ポリゴン」へ変更。
  - `bridgeId`、3点以上のポリゴン、外周ポリゴンのサイズ・中心線交差・親橋との関係の検証は維持。
- アプリ
  - 使い方画面へ、橋脚は橋桁や影・余裕幅を含めず外周を直接囲むことを追加。
  - `StaticObstacle` の橋脚ポリゴンと `bridgeId` のシリアライズテストを、5点の不規則な外周ポリゴンで明示。
  - プリセット読込は元々ポリゴン座標をそのまま `StaticObstacle` に渡すため、警告ロジックや既存座標JSONは変更していない。
- 要件文書
  - 矩形化・実測幅を要求する記述を削除し、外周ポリゴンの直接入力へ同期。

## 操作方法

1. プロットツールで親の橋を選択する。
2. `橋脚（外周ポリゴン）` を追加する。親の橋を選択していれば `bridgeId` が自動入力される。
3. 「頂点を追加」で、橋桁全体ではなく水中に立つ柱の外周を3点以上クリックする。
4. 影や周囲の余裕幅は含めず、頂点を移動・座標一覧で必要に応じて微調整する。
5. 航空写真だけで形状を確定できない場合は、確認状況を `draft` または `aerial_only` のままにし、現地確認後に更新する。
