# 障害物座標プロットツール 実装記録（2026-07-28）

対象要件: `docs/design_notes/2026-07-28_障害物座標プロットツール_要件定義.md`

## 今回完了したこと

- `tool/obstacle-plotter/` にローカル専用の React + TypeScript + Vite ツールを追加した。
  - Apple MapKit JS の短命JWTをローカルAPIだけで発行する。秘密鍵はブラウザへ返さず、`127.0.0.1` にだけ待受する。
  - オブジェクト作成、頂点追加・座標表編集、岸の向き反転、Undo/Redo、IndexedDB復元、JSON/GeoJSON/KML/レイアウト書出し、事前検証、変更適用パッケージ出力を実装した。
  - MapKitの認証情報が無い場合はAPI起動を失敗させる。地図SDKが読み込めない時だけ、座標を失わないための簡易平面表示へ退避する。
- 既存プロフィールに実測でない `ashoreAreas`、`navigableWaters`、`channelCenterline` は追加していない。
  - アプリは `ashoreAreas` が無いとき「陸上」と判定せず、警告音を止めない。
  - 明示的な航路中心線が無いときは、基準線から推定せず直線予測へ退避する。
- `AshoreDetector` を危険区域ポリゴンではなく `ashoreAreas` 専用の判定へ変更した。水面復帰は即時、陸上確定は精度を考慮した内側余白と30秒継続を必要とする。
- 共有校正を `fixed_obstacle_calibrations_v3` の名前付きMap形式へ移行した。v2は読み取り専用で維持し、最初の公開時にv3へ移す。
- `tool/generate_hazard_constants.dart` を追加し、同梱JSONからDartのID/頂点数定数とFirestore Rulesの全ID許可リストを生成するようにした。CIにも `--check` を追加した。
- v3共有校正の未知ID・壊れた頂点配列が、他の有効な校正を失わせないことをテストした。

## 未完了・実施前のこと

要件全体のうち、以下はまだ完成していない。未実測座標を推測して埋めないため、ここで止めている。

1. プロッタの GeoJSON/KML **読込**、フォルダ階層・ドラッグ並べ替え、Firebase読込UI、校正ベイク、管理対象流木の変換、直接書込み（明示確認付き）は未実装。Firebaseの読取り専用コードと変更適用パッケージ出力はあるが、UIからは呼んでいない。
2. レイアウトJSONの読込と、すべての要件上のビュー設定・操作は未実装。現在は主要編集と書出しを優先している。
3. `ashoreAreas`・`navigableWaters`・`channelCenterline` の実座標入力、衛星画像との比較、現地確認、既存座標の境界・向き確認は未実施。これは安全上、担当者がプロッタで描画して確認する必要がある。
4. アプリ地図上の陸上領域・航路中心線の表示、v2→v3のアプリ起動時自動移行、Firestore Rules Emulator、実機・水上・音量の確認は未実施。v2→v3は現状「次回共有公開時」にのみ移行する。
5. Firestore Rulesの本番デプロイ、Archive/TestFlight、MapKit実地表示は行っていない。ローカルのビルドやテスト成功はこれらを保証しない。

## 2026-07-29 追記: MapKit JSの地図が表示されない不具合

ユーザー環境でAPI起動とトークン取得までは成功したが、画面に
`mapkit.Map is available after loading the following library: map.` が表示された。
原因は、`mapkit.init`の直後に`new mapkit.Map`を実行し、MapKit JS 5の`map`ライブラリ読み込みを待っていなかったこと。
`tool/obstacle-plotter/src/map/MapCanvas.tsx`で`mapkit.load('map', callback)`（Promiseを返す版も対応）を待ってから地図を生成するよう修正した。

検証:

```bash
npm run build --cache /private/tmp/obstacle-plotter-npm-cache
npm test
```

どちらも成功。起動中のViteが変更を反映した後、ブラウザを再読み込みする。反映されない場合はターミナルで`Control+C`を押して`npm run dev`を再実行する。
