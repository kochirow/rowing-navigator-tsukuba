# iOS 高リフレッシュレート設定メモ

## 結論

`ios/Runner/Info.plist` の `CADisableMinimumFrameDurationOnPhone` は、**削除せず `<false/>` で明示する**。

```xml
<key>CADisableMinimumFrameDurationOnPhone</key>
<false/>
```

本アプリでは地図表示に高リフレッシュレートは不要であり、航行中の電池消費・発熱を抑える方針である。

## なぜ削除しないのか

Flutter の iOS 移行処理は、このキーが `Info.plist` に存在しない場合、`<true/>` を自動追加することがある。したがってキーを削除すると、`flutter build ios` や iOS 設定の再生成後に高リフレッシュレートを許可する設定が復活しうる。

`<false/>` を残しておけば、Flutter はキーを追加し直さず、アプリ側の方針も維持できる。

## 変更時の確認

設定を触った後は、次で値を確認する。

```zsh
cd "/Users/gotoukousei/obsidian/My_Obsidian/漕艇部/桜川プロジェクト/桜川アプリ/rowing-navigator-tsukuba"
plutil -extract CADisableMinimumFrameDurationOnPhone raw -o - ios/Runner/Info.plist
flutter test test/ios_power_config_contract_test.dart
```

両方とも `false` とテスト成功になればよい。キーを削除したり、`<true/>` に変更したりしない。
