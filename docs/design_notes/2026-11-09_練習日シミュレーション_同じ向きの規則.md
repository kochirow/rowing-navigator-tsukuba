# 練習日シミュレーションで同じ向きの規則を確かめる(2026-11-09)

## 目的

PR #141 で、向きの差30°以内の他艇への警告を表示だけにした(並走・縦列)。追いつく側にだけ安全網を残している。
これが、次の2点で実際の練習に合っているかを確かめる。

- 並走・鬼ごっこの練習中に鳴らないか
- すれ違い・逆側を漕ぐ艇・止まった艇・回頭・追突で、鳴るべきときに鳴るか

## 方法

ツール: `tool/simulate_alert_timing.dart`(CI では走らない)。

- 艇の動き・測位誤差・通信のモデルは、2026-10-23 のもの(`2026-10-23_警告の鳴り始め_シミュレーション.md`)を使う。
- 判定はアプリの部品をそのまま通す。順に、外挿 → `assessRisk`(レーン付き)→ `SafetyOrchestrator`。
- 今回、`processAssessment` に自艇・他艇(受信した生の値と相手の測位時刻)と航路中心線を渡すようにした。
- 比べる設定は2つ。今の設定(13秒・10秒)のまま、同じ向きの規則を入れた場合(`D13_L10`)と、外した場合(`D13_L10_noSameDir`)。

```bash
flutter test tool/simulate_alert_timing.dart --dart-define=SIM=fleet --dart-define=MINUTES=75 --dart-define=FLEET_RUNS=3 --dart-define=OUT=/tmp/fleet.json
flutter test tool/simulate_alert_timing.dart --dart-define=SIM=conflict --dart-define=VARIANT_SET=current --dart-define=RUNS=80 --dart-define=OUT=/tmp/conflict.json
```

### 練習日(`SIM=fleet`)

組み方と練習の中身は、実機ログ(2026-11-07 桜川・11/03 霞ヶ浦)に合わせた。

| 艇 | 練習 |
| --- | --- |
| 4+ ×2 | 並走でピース(横4〜8m)。休憩は横12〜17mで並んで止まる(11/07 学園大橋の上流と同じ)。回頭も一緒にする |
| 2x ×2 | 鬼ごっこ。真後ろから0.4〜0.8m/s速く追い、後ろ45mで中心線側へ5m出て抜き、役を入れ替える。反対から艇が来ていれば後ろ20mで待つ |
| 1x ×2 | 通常の練習。1艇は往路ごとに35%で逆側(左)を漕ぐ(11/07 の1回目の下りは95〜100%の時間を左側で漕いでいた) |

- 4艇の日は、4+ ×2・2x(通常)・1x(逆側あり)にした。
- 水域は桜川上流・桜川河口・霞ヶ浦の3つ。75分の練習を、6艇・4艇それぞれ3回ずつ走らせた。合計112.5艇・時間。
- 艇は見張りをする。正面から来る艇とは右へよけ、遅い艇は追い越す。

### 危ない場面(`SIM=conflict`)

よけなかった場合の場面を、各水域80回ずつ走らせた。

- 正面(同じレーン・横3〜7mずれ)
- レーン上に止まった艇
- 同じレーンで後ろから追いつく
- レーン上で回頭する艇
- 橋脚

船体どうしが当たるまで見て、その何秒前に鳴ったかを数えた。

## 結果1: 組んで漕ぐ練習では、ほぼ鳴らない

組んで漕いでいる時間(同じ向き・両艇とも漕いでいる)のうち、相手への他艇の音が出ていた割合:

| 練習 | 規則なし | 規則あり |
| --- | --- | --- |
| 4+ の並走 | 86.5% | 0.2% |
| 2x の鬼ごっこ | 58.9% | 1.5% |

鬼ごっこの1.5%は、抜くときに、横に並ぶ手前の数秒だけ鳴る安全網である。

## 結果2: 隠れていた音が聞こえるようになる

1艇1時間あたりの、音が出ていた秒数:

| 水域 | 規則なし | 規則あり | 規則ありの内訳(多い順) |
| --- | --- | --- | --- |
| 桜川上流 | 1931 | 875 | 岸241・カーブ200・橋170・逆走注意123・他艇101 |
| 桜川河口 | 1863 | 472 | 逆走注意185・カーブ110・他艇102・流木52 |
| 霞ヶ浦 | 1647 | 362 | 逆走注意193・岸115・他艇48 |

規則を入れると、岸・カーブ・橋の音の秒数は増える(桜川上流の岸は151→241秒)。音声は1本なので、組の相手への連続音の陰で、これらが鳴れずにいた。

実機との比較:

- 11/07 桜川(2.2時間)は、音のある秒が1時間あたり約1065秒、鳴り始めが約146回だった。規則ありのシミュレーション(桜川上流875秒・113回)と同じ程度である。
- 内訳では、実機は逆走注意が多い(443秒)。11/07 は1回目の下りを左側で漕いだためである。

## 結果3: すれ違いの警告は、規則ありの方が届く

練習日に起きた接触:

- 船体どうしの接触は、向きによらず数えた。
- オールの接触は、正面・横切りだけを数えた。

「鳴った」は、鳴るべき端末が当たる3秒以上前に鳴った場合である。鳴るべき端末は、同じ向きなら後ろの艇、それ以外は両方とした。

| 種類 | 件数 | 規則あり(どれか / 全員 / 中央値) | 規則なし |
| --- | --- | --- | --- |
| 正面(通常のすれ違い) | 83 | 73 / 42 / 12秒 | 48 / 9 / 10秒 |
| 正面(逆側を漕ぐ艇) | 47 | 47 / 37 / 12秒 | 39 / 19 / 12秒 |
| 横切り・回頭(組以外) | 21 | 13 / 5 / 7秒 | 16 / 8 / 8.5秒 |
| 鬼ごっこの組の船体接触 | 20 | 7 / 7 / 7.5秒 | 19 / 19 / 18秒 |
| 組以外の同じ向きの船体接触 | 5 | 2 / 2 / 7秒 | 4 / 4 / 15.5秒 |
| 並走の組の船体接触 | 5 | 2 / 2 / 6秒 | 5 / 5 / 10秒 |
| 組の回頭・休憩中(両艇低速) | 193 | (低速静音の対象) | |

- すれ違いでは、規則ありの方が両方の端末で鳴る。組の相手への連続音が、正面から来る艇の警告を隠していたためである。
- 鬼ごっこ・並走の組の船体接触は、多くがモデルの動きによるものである。
  - 抜く途中に横へゆっくり寄る(前後の距離が縮む速さ0.2〜0.45m/s)
  - 抜いた直後に前へ入りすぎる
  
  前後の距離が縮む速さが0.5m/s未満、または前の艇の方が速いので、安全網の対象外である。規則なしで鳴っているのは、組んでいる間ずっと鳴っているためである。
- 組の回頭・休憩中の接触は、4〜8mで並んでその場で回るモデルによるもので、両艇とも分速100mより遅い(低速静音)。

## 結果4: 安全網を直した(横2m → 中心線基準・横8m・並んだら終える)

最初の安全網(自艇の向き基準・横2m以内)は、同じレーンで後ろから当たる場面で、船体が当たる前に鳴らないことが多かった。

原因は横の距離の測りにくさである。

- 2台の端末の測位の誤差は、相対で約2.5mあり、数十秒かけてゆっくり変わる。6秒平均でも消えない。
- 自艇の向きを基準にすると、舵のぶれ(数度)とカーブで、30m先の横の距離がさらに数mずれる。
- 真後ろ(横0m)の艇を、横6mと測った例があった。

案ごとの比較(同じ入力を渡した検証用の判定。各水域約63回の追突):

| 案 | 当たる前に安全網が立たなかった数(霞ヶ浦 / 河口 / 上流) | 練習日の安全網の時間(1艇1時間) |
| --- | --- | --- |
| 自艇の向き基準・横2m(最初の案) | 32 / 38 / 26 | 6秒 |
| 中心線基準・横2m | 28 / 41 / 29 | 7秒 |
| 中心線基準・横5m | 10 / 8 / 7 | 28秒 |
| **中心線基準・横8m・横に並んだら終える(採用)** | **4 / 2 / 0** | **12秒** |

採用した形での、アプリと同じ判定(提示まで通す)の結果:

| 場面 | 規則あり: 船体が当たる前に鳴らず / 当たった数(鳴り始め p10・p50) | 規則なし |
| --- | --- | --- |
| 追突(霞ヶ浦) | 5 / 64(2秒・7秒) | 0 / 64(10秒・21秒) |
| 追突(桜川河口) | 3 / 63(3秒・7秒) | 0 / 63 |
| 追突(桜川上流) | 1 / 62(2秒・9秒) | 0 / 62 |
| 正面・止まった艇・回頭・橋脚 | 規則なしと同じ | |

採用した形の考え方:

- 後ろから当たるのは、艇首が前の艇の艇尾に届く瞬間である。そこを過ぎて当たっていなければ、横を抜けている。
- そこで横の距離は、明らかに離れた艇(8m超)を外すだけにする。代わりに、横に並んだら終える。
- 横4mで抜くときは、並ぶ手前の数秒(1m/s差で約8秒)だけ鳴る。

## 限界

- 艇の動きはモデルである。組んで漕ぐ艇の横の保ち方は、周期約15秒で積極的に戻すとした。抜くときの寄り方・前への入り方は、実際の漕ぎ方で確かめていない。
- 追突で、まだ船体が当たる前に鳴らないのが約5%ある。鳴り始めも p10 で2〜3秒と、目標の4秒より短い。
  - 主な理由は、前後の距離が縮む速さの推定(10秒の傾き)と測位の誤差である。
  - 音声が1本なので、岸などの音が先に鳴っていることもある。
- 実機で同じ向きの安全網を確かめたログはまだない。次の練習から、他艇の警告の記録に相手の向き・前後・横(`targetHeadingDeg`・`targetAlongMeters`・`targetLateralMeters`)が残る。
