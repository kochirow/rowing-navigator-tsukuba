# 警告の鳴り始め(秒)をシミュレーションで比べる(2026-10-23)

## 目的

衝突警告の鳴り始め(確実な当たり予測 13秒・確度の低い当たり予測 10秒)が
適切かを、**複数艇の練習を数式で作って**確かめる。人が音を聞いてから反応できるかは
ここでは扱わない(利用者の指示)。見るのは次の2つだけである。

- **過剰警告**: 正常な練習で、よけなくても当たらない相手に鳴る割合と、鳴っている時間
- **余裕**: よけなければ当たる場面で、危険接近の何秒前に鳴り始めるか

桜川で複数艇が同時に漕いだ実機ログは無い(2026-08-06 の4艇は最も近づいても21m)。
そこで艇の動き・測位誤差・通信を確率モデルで作り、真の位置を知っている状態で数える。
これは航空の TCAS が認証前に数百万件の模擬遭遇で評価された方法、自動車の衝突警告で
「不要な警告」と「間に合った割合」を並べて閾値を選ぶ方法(SOC 曲線)と同じ考え方である。

## 方法

ツール: `tool/simulate_alert_timing.dart`(`flutter test` で動かす。CIでは走らない)。

### 判定はアプリの部品をそのまま使う

アプリの航行中の1秒ごとの処理と同じ順で呼ぶ。

1. 受信した他艇のうち6秒より古いものを落とす(`boatPredictionTimeoutSeconds`)
2. `CollisionRiskEvaluatorService.extrapolateToNow` で現在まで外挿する
3. `assessRisk`(同梱の危険区域・`ChannelLaneResolver` 付き、予測地平 = 鳴り始め)
4. `SafetyOrchestrator.processAssessment`(提示ポリシー・FSM・静音規則を含む)
5. `SafetySnapshot.audioDirective` を「その秒に鳴っていた音」とする

鳴り始めの設定ごとに、評価器と提示の状態を別々に持つ。

### 艇の動き(真の状態)

航路中心線に沿った座標(川に沿う距離・横位置)で動かし、地理座標へ戻す。

| 要素 | モデル | 根拠 |
|---|---|---|
| 速さ | ピース(3.3m/s)・流し(2.55m/s)・時々休憩を繰り返す。艇種で +0〜0.6m/s。漕ぎの強さの揺らぎ(±0.3m/s・15秒)、ストローク中の増減(±20%) | 実機ログの漕いでいる区間: 中央値2.8m/s・90パーセンタイル3.5m/s |
| 横位置 | 艇ごとに漕ぐ横位置を選ぶ。進行方向の右が正で、桜川上流 平均8m・標準偏差7m、河口 10m・8m、霞ヶ浦 -37m・24m。レーンの外側の端から8m内側まで | 実機ログ: 上流 中央値7.2m・四分位1.1〜16.5m、霞ヶ浦 中央値-38m。河口は記録が約19分しかなく右側通行と合わないため、運用前提に合わせた |
| 横の揺れ | 選んだ横位置へ戻る減衰振動(周期約60秒)+ 乱れ | 下の照合で決めた |
| 回頭 | 航路の端の50〜160m手前で止まり、約42秒でその場で180度回る。近くで別の艇が回頭中なら待つ | |
| 見張り | 正面から来る艇が自分の線上(横12m以内・70m以内)なら互いに右へ5m。遅い艇・止まった艇は横12m空けて追い越し、反対から艇が来ていれば後ろ30mを保つ。横並びは片方が下がる | 実際の漕手はアプリと別に振り返って見ている。これが無いと正常な練習で艇が素通りでぶつかる |

### 測位・推定の誤差と通信

- 推定位置の誤差は、推定速度の誤差(0.08m/s・時定数10秒)を積分したもの(60秒で戻る)。
  アプリの Kalman の出力は滑らかで、位置だけが細かく跳ねることはないため。
- 推定の速さには進行方向だけ誤差(0.2m/s・3秒)を足す。0.6m/s 未満では方位を当てにしない。
- 送信は 停止中10秒 / 300m以内に艇がいれば2秒 / それ以外5秒、0.2〜1.0秒遅れて届く。

### モデルの照合(T秒先の予測のずれ)

アプリと同じ川なり予測で「T秒先の予測位置」と「実際にいた位置」の差を、
実機ログ15本(約13.2時間)とシミュレーションで比べた(90パーセンタイル [m])。

| 予測の先 | 横・実機(桜川) | 横・シミュレーション(上流) | 川沿い・実機 | 川沿い・シミュレーション |
|---|---:|---:|---:|---:|
| 3秒 | 0.7 | 0.8 | 3.1 | 2.5 |
| 8秒 | 2.5 | 2.9 | 7.9 | 6.7 |
| 13秒 | 5.0 | 5.5 | 13.7 | 11.1 |
| 20秒 | 9.0 | 9.5 | 22.7 | 18.0 |

横方向は実機より1〜2割大きく(= 鳴りやすい側)、川沿いは2割ほど小さい。
霞ヶ浦の横方向は実機より大きめ(13秒で 6.3m 対 4.9m)。

正常な練習の音の量も、実機ログを今の判定で再生した値と比べた。
桜川を含む2本の実機ログは岸 56〜178秒/時・橋 96〜130秒/時、
霞ヶ浦のみのログは岸 9〜125秒/時(中央値約40)だった。

### 「当たる」の定義

- **危険接近**: 真の位置で、自艇の排他領域が相手の船体領域に重なった(アプリが守ろうとしている状態)
- 橋脚は、真の船体領域が橋脚に重なったとき
- **よけなくても当たらない遭遇**: 120m以内に近づいた時点で、互いの予定の横位置の差が
  「重ならないための中心間距離(排他半幅+相手の船体半幅+2.2m)」+2m 以上ある遭遇。
  ここで鳴った音は過剰警告とみなす

## 結論

**鳴り始めは今の13秒(確度が低いときは10秒)のままでよい。**
秒数を変えて得られるものより、次の2つを直すほうが効果が大きい。

1. **音声1本の取り合い(桜川上流)。** 危ない場面の2〜6%で、他艇への警告は
   間に合って立っていたのに、音声を岸・橋の読み上げが使っていて
   「他艇に注意」が危険接近まで流れなかった(何かの音は鳴っている)。
   音声の対象を選ぶ順序が「いま重なっている」を到達時間より先に見るため
   (`AlertCandidateComparator.compare`)、橋の下・岸際を通る間は、
   近づいてくる他艇の読み上げが入れない。秒数を延ばしても直らない。
   **→ 同日、岸・橋(桁)への重なりを音声の順位だけ下げて直した**
   (`compareForAudio`)。案を比べた見積もり(書き出した候補で選び方だけを
   差し替えて再現、2秒ロックは省略): 他艇を最優先にする案は取りこぼしが
   0%になる代わりに橋脚・杭の警告の7%で音声が流れなくなった。採用した案は
   取りこぼし0%で橋脚等への影響は無く、岸・橋の警告の1.5%で音声が流れず
   3.8%で遅れる(中央値7秒・最大17秒)。岸・橋を1回だけ読み上げにする案は
   取りこぼしが0〜2.8%残り、岸へ寄り続けても1回しか鳴らなくなる。
2. **正常な練習での鳴りすぎ(桜川)。** 鳴り始め13秒で、よけなくても当たらない
   遭遇の28%(上流)・19%(河口)で鳴る。9秒まで縮めても23%・16%残る。
   原因は秒数ではなく、正面のすれ違い(上流の他艇の音の47%)と
   同じ向きの追い越し・追従(32%)で、レーンの間隔に対して
   「重ならないための中心間距離」(小艇9.7m・8+ 11.2m)が広いこと。

### 秒数を変えたときの得失(数字は下の表)

- **余裕**: 危険接近の何秒前に警告が立つかは、中央値でほぼ「鳴り始め − 1〜3秒」で、
  鳴り始めを1秒延ばすと1秒増える。13秒では、正面から来る艇に対して
  下位10%でも9〜10秒前(8+の停止時間相当8.15秒を上回る)。
  止まっている艇・回頭中の艇・追い越しのように近づき方が遅い・不規則な場面では
  下位10%が5〜8秒前まで下がる。これを8秒以上にするには16〜18秒が要る。
- **鳴りすぎ**: 繰り返し音の時間は1秒延ばすごとに約4%増える。
  13秒 → 16秒で、上流 769 → 868秒/艇時(+13%)、河口 346 → 398(+15%)、
  霞ヶ浦 207 → 229(+11%)。よけなくても当たらない遭遇で鳴る割合も
  上流 28% → 32%、河口 19% → 22%。
- **確度が低いときの鳴り始め**(8.5〜13秒): 鳴る時間の差は ±3%、
  余裕の差は1秒以内で、どちらにもほとんど効かない。10秒のままでよい。
- **桜川上流で練習中に鳴っている時間**は、13秒で1艇あたり約770秒/時
  (= 約21%、うち他艇375・岸230・橋と橋脚164)。秒数より、鳴りすぎの
  原因(上の2.)と岸・橋の音を減らすほうが効く。

### このシミュレーションで言えないこと

- 人が音を聞いてから止まるまでの時間(利用者の指示で扱っていない)。
  停止時間8.15秒も実測ではない継承値である(艇種別安全定数の根拠台帳)。
- 実際の漕手のよけ方。見張りは単純な規則で作っており、正常な練習でも
  上流で18艇時間に121件の危険接近(主に追い越しの横並び)が起きている。
- 霞ヶ浦は北岸しか危険区域が無い。霞ヶ浦の他艇の音は、同じ向きの
  追い越し・追従が64%を占める。

## 結果

鳴り始め N秒 = 確実な当たり予測の鳴り始めと予測地平。表の「不確か X秒」は、
鳴り始め13秒のまま確度の低い当たり予測の鳴り始めを変えたもの
(それ以外の行は min(10, N − 0.5) 秒)。

「よけなくても当たらない遭遇」で鳴った割合が過剰警告、
「よけなければ当たる遭遇」は見張りでよける前に鳴った割合。
