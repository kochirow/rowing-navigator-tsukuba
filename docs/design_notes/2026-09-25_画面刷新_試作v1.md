## 3. 画面ごとの提案(試作で見られる)

### ① 出艇前(ホーム)
- 下に「操作の台」を置き、`航行スタート`(全幅・前回の名前/艇種/座席を併記)、`設定を変えて開始`、`監視スタート` をまとめる。
- **出航前チェック**を上部に1つの表示で出す。良好なら「すべて良好」、悪い項目(GPS・音量)だけを黄色で横に出す。
  **開始はブロックしない**(原則1)。中身は「端末とデータ」と同じ情報。
- メニューは先頭にタイル3つ(練習記録・チーム・使い方)、その下は現行の一覧。並びは状況で変えない(既存の約束)。説明は1行。

### ② 航行中
- 能力低下バッジに状態まで書く(`GPS 弱い ±14m`)。既存テストが固定している `他艇受信: 利用不可` の文言は変えない。
- 測位前は薄い `—:—` と「測位待ち」。
- 主計器の上端に指標色の細い線(ペース=ティール、レート=青)。記録画面のグラフと同じ色。
- 警告バナーの見た目・判定・脈動は変えない。本警告中に計器を縮める既存の挙動も同じ。

### ③ 記録一覧
- 集計カードに「週ごとの距離」の棒(直近8週)。選んだ期間の棒をティールにする。
- 月ごとの見出し(本数・距離)、カードに航跡の小さな絵・艇種と座席・セットの要約。
- 1分未満・100m未満の記録は「短い記録 N件」として下に畳む。**消さない。** 整理(削除)は確認つき。
- 一覧は全期間のまま(集計だけが期間で変わる、現行の設計)。

### ④ 警告の設定
- 「残り秒数」の1本の軸に、連続音・断続音・音なしの帯と、艇種ごとの止まるまでの時間(1x 6.95秒 / 2x 6.60秒 / 4x 6.68秒 / 8+ 8.15秒)を並べる。
  印をつまんで動かせる。範囲は現行どおり(本警告 8.5秒以上・0.5秒刻み・予告未満、予告 9〜25秒・1秒刻み)。
- 値は大きな −/+ ボタンでも変えられる。既定から変えた項目に「変更」、戻すボタンは項目ごと。
- 当たり判定は断面図(基準線の左右に広がる帯)で見せる。範囲は現行どおり 0〜30m。
- 変更があるときだけ下に保存バー(件数・元に戻す・この端末に保存)。保存後は「この端末に保存済み・チームには未公開」と `チームに公開…` を出す。

## 4. 色の規則(実装で守ること)

- **赤・橙・黄は危険の段階だけ。** ボタンの面、指標、装飾に使わない。
  - 「航行終了」「監視終了」は面を赤で塗らず、文字と枠だけ赤(P0で実施済み)。
- **レート(SR)の色は橙から青へ変える**(記録画面も)。橙は「予告(断続音)」の色で、同じ画面に並ぶと見分けにくい。
  暗色 `#6EA8FF` / 明色 `#2F6FE0`。1漕距離は紫のまま。
- 地図(通常・高コントラスト)は明るいままにする。地図の上のステータスバーは暗い文字(P0で実施済み)。

## 5. P0で直したもの(記録)

| 問題 | 対応 |
| --- | --- |
| 使い方の秒数「約7秒・約10秒」が実際(10秒・13秒、変更可)と違う | 効いている値を渡して表示 |
| 記録一覧に `r_8p` | `boatTypeDisplayLabel` で「8+」 |
| 「今月の記録はありません」の下に8月の記録が並ぶ | 一覧は全期間と見出しに明記、空状態の文言を修正 |
| ダークモードで地図の上の時刻・電池が白文字で読めない | `AnnotatedRegion` で地図の明暗に合わせる |
| コンパスが電池表示に重なる | 地図のパディングを上下同量ずつ足す(カメラ位置は不変) |
| 航行スタートの文字が約2.3:1 | 既定の文字色を `onPrimary` に |
| 航行終了が半透明で地図の文字が透ける | 不透明の面+赤い文字と枠 |
| 航行設定シートの×がスクロールで消える | つまみと×をスクロールの外に固定 |
| 12px未満の文字が約30か所 | 12pxへ(グラフの軸だけ11px) |

## 6. 決めてほしいこと

1. **出艇前の `航行スタート` を押したら、シートを開かずに前回の設定で始めてよいか。**
   ボタンに名前・艇種・座席を書くので別人の設定には気づける。変えたいときは `設定を変えて開始`。
2. **記録画面のレート(SR)の色を、橙から青に変えてよいか。**
3. **短い記録(1分未満・100m未満)を畳む基準はこれでよいか。**

## 9. 試作 v3(2026-09-25、航行中の計器・警告の向き・操作の位置)

### 9.1 計器
- 重要度は **ペース > レート > 距離 > 時間**(利用者)。文字の大きさもこの順: 76 / 70 / 46 / 36。
- 時間は **漕いでいる時間だけ**。「漕ぎ」とは書かず、`chrono` と小さく添える(NK SpeedCoach の表記)。経過時間(全体)は出さない。
- 2段目は文字数に応じた幅で、距離を時間より一回り大きく。12,480m・1:28:40 でもはみ出さないことを試作で確認。

### 9.2 警告の向きは「画面の中の位置」で
- 地図は進行方位+180度で回るので、**画面の位置 = 漕手の体から見た向き**(右後ろ=画面の右下、真後ろ=画面の下の中央)。
  チップは**画面の端**に置く(v4、利用者)。自艇から脅威の方向へ伸ばした線が、計器カードの下〜画面の下端の範囲で画面の端に当たる所。
  端に寄るほど向きが一目で分かり、地図の中央(自艇の周り)も空く。矢印も脅威へ向け、本警告はその方向の画面の端が赤く光る。
- **文字の「右」「後方」は使わない。** 既存の `relativeDirectionLabelOf` は艇の進行方向を基準にした語(「右」=艇の右舷=漕手の左)。
  現行バナーが向きを出していないのはこの食い違いのためで(`safety_banner.dart` の `_detailLabel`、`widget_test.dart` が `右 5秒` を出さないことを固定)、
  位置で出せば翻訳が要らない。実装では `ThreatInfo.relativeBearingDegrees` を画面角 = 180 + 相対方位 で置く。
- 方位が信頼できないとき(不変条件10)は向きを出さない。チップは定位置に矢印なし、画面の縁全体を光らせる。

### 9.3 操作は左下へ
- すれ違う艇は漕手の右後ろ(画面の右下)から来ることが多い(右側通行で自艇は画面の左寄り、対向艇は右を通る)。
  真後ろ(画面の下の中央)は進行方向の見通し。どちらも空けるため、追跡・メニュー・航行終了を左下の縦1列にまとめる。
- 航行終了は押すとき余裕があるので小さく(「終了」40px高)。確認ダイアログは維持。

### 9.4 決めてほしいこと(追加)

## 10. 試作 v5(2026-09-26)

- **自艇の位置は変えない。** 追跡中(既定)は画面の横中央・上から45%に固定(`navigationSelfBoatScreenRatio`、カメラが毎回自艇へ寄せる)。
  v4までの試作は中央から26pxずれていた(試作だけの違い)ので直した。
- **警告は「脅威の向きの画面の端が赤く点滅」だけ**(利用者)。秒数・対象の絵のチップはやめる。
  **予告と本警告は見た目を分けない。** 漕手にとってはどちらも後方確認の合図で、切迫度の違いは音(断続音/連続音)が持つ。
  向きが分からないとき(不変条件10)は画面の縁全体を点滅。表示のみ(音なし)の候補は光らせない。
  読み上げ(`liveRegion`)用の文言は画面に出さずに残す。
- **他艇の視認性。** 現状は航行中の全艇が同じ濃い青みグレー `#263238`(明るい地図用)+名前ラベル常時。監視中だけ艇ごとの識別色。
  暗い地図では濃い色が沈むので、**明るい灰白 `#EEF3F7` の塗り+黒い縁+淡い光輪**にして、どの背景でも一番明るい物にする。
  艇ごとの色分けはしない(色を暗記させない・赤=自艇を守る、の既存方針)。**警告の相手だけ縁を赤く**して、光った画面の端と地図上の艇を結ぶ。
  実装では `BoatPalette.otherBoat` を地図の明暗別にする(高コントラストの明るい地図では従来の濃色)。

決めてほしいこと(追加):
7. 他艇の灰白は中央線(白い破線)と紛れないか(紛れるなら淡い水色寄りに)。
8. 警告の相手の縁だけ赤くするのは、「赤は自艇だけ」(`BoatPalette.myBoat`)の約束に触れる。塗りは灰白のまま縁だけ赤なら許容できるか。
