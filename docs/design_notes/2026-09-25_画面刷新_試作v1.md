## 1. 決まったこと

- **アクセントはティール1色にする**(2026-09-25 利用者)。暗色 `#35D6C8`(文字 `#04221F`)、明色 `#0A8F86`(文字 白)。
  いまの水色 `#5CB4D8` から置き換える。
- **画面の見た目は記録画面の `RecordPalette` を土台にする。** 面の4段(背景・面・一段上・さらに上)と線色、
  大きな等幅数字、角丸22px前後のカード。
- 手順は「P0の修正 → HTML試作 → 決まった画面から実装」。P0 は `fix(ui): 画面の読みにくさと説明の食い違いを直す(P0)` で修正済み。

## 2. 借りた考え方(リサーチ)

| 考え方 | 出典 | このアプリでの形 |
| --- | --- | --- |
| 航行中は航行に要るものだけ | Apple HIG Workouts | 計器・警告・終了だけ(いまの方針のまま) |
| 主計器は4つ、大きく、位置固定 | NK SpeedCoach(レート・ペース・時間・距離)、Garmin | 計器カードの型は維持 |
| 赤・橙・黄は危険の段階専用 | IEC 60601-1-8(警報の色と優先度) | 指標の色から橙を外す(§4) |
| 隠れたメニューは見つからない | NN/g | よく使う3つをタイルで先頭に |
| 設定は少なく、良い既定値で | Apple HIG Settings、Android の設定画面の型 | 前回設定のまま1タップ出艇、設定画面の既定/変更の表示 |
| 空の画面では次の一手を示す | NN/g | 記録一覧の空状態 |

## 3. 画面ごとの提案(試作で見られる)

### ① 出艇前(ホーム)
- 下に「操作の台」を置き、`航行スタート`(全幅・前回の名前/艇種/座席を併記)、`設定を変えて開始`、`監視スタート` をまとめる。
- **出航前チェック**を上部に1つの表示で出す。良好なら「すべて良好」、悪い項目(GPS・音量)だけを黄色で横に出す。
  **開始はブロックしない**(原則1)。中身は「端末とデータ」と同じ情報。
- メニューは先頭にタイル3つ(練習記録・チーム・使い方)、その下は現行の一覧。並びは状況で変えない(既存の約束)。説明は1行。

### ② 航行中
- 能力低下バッジに状態まで書く(`GPS 弱い ±14m`)。既存テストが固定している `他艇受信: 利用不可` の文言は変えない。
- 測位前は薄い `—:—` と「測位待ち」。
- 主計器の上端に指標色の細い線(ペース=ティール、レート=青)。記録画面のグラフと同じ色。
- 警告バナーの見た目・判定・脈動は変えない。本警告中に計器を縮める既存の挙動も同じ。

### ③ 記録一覧
- 集計カードに「週ごとの距離」の棒(直近8週)。選んだ期間の棒をティールにする。
- 月ごとの見出し(本数・距離)、カードに航跡の小さな絵・艇種と座席・セットの要約。
- 1分未満・100m未満の記録は「短い記録 N件」として下に畳む。**消さない。** 整理(削除)は確認つき。
- 一覧は全期間のまま(集計だけが期間で変わる、現行の設計)。

### ④ 警告の設定
- 「残り秒数」の1本の軸に、連続音・断続音・音なしの帯と、艇種ごとの止まるまでの時間(1x 6.95秒 / 2x 6.60秒 / 4x 6.68秒 / 8+ 8.15秒)を並べる。
  印をつまんで動かせる。範囲は現行どおり(本警告 8.5秒以上・0.5秒刻み・予告未満、予告 9〜25秒・1秒刻み)。
- 値は大きな −/+ ボタンでも変えられる。既定から変えた項目に「変更」、戻すボタンは項目ごと。
- 当たり判定は断面図(基準線の左右に広がる帯)で見せる。範囲は現行どおり 0〜30m。
- 変更があるときだけ下に保存バー(件数・元に戻す・この端末に保存)。保存後は「この端末に保存済み・チームには未公開」と `チームに公開…` を出す。

## 4. 色の規則(実装で守ること)

- **赤・橙・黄は危険の段階だけ。** ボタンの面、指標、装飾に使わない。
  - 「航行終了」「監視終了」は面を赤で塗らず、文字と枠だけ赤(P0で実施済み)。
- **レート(SR)の色は橙から青へ変える**(記録画面も)。橙は「予告(断続音)」の色で、同じ画面に並ぶと見分けにくい。
  暗色 `#6EA8FF` / 明色 `#2F6FE0`。1漕距離は紫のまま。
- 地図(通常・高コントラスト)は明るいままにする。地図の上のステータスバーは暗い文字(P0で実施済み)。

## 5. P0で直したもの(記録)

| 問題 | 対応 |
| --- | --- |
| 使い方の秒数「約7秒・約10秒」が実際(10秒・13秒、変更可)と違う | 効いている値を渡して表示 |
| 記録一覧に `r_8p` | `boatTypeDisplayLabel` で「8+」 |
| 「今月の記録はありません」の下に8月の記録が並ぶ | 一覧は全期間と見出しに明記、空状態の文言を修正 |
| ダークモードで地図の上の時刻・電池が白文字で読めない | `AnnotatedRegion` で地図の明暗に合わせる |
| コンパスが電池表示に重なる | 地図のパディングを上下同量ずつ足す(カメラ位置は不変) |
| 航行スタートの文字が約2.3:1 | 既定の文字色を `onPrimary` に |
| 航行終了が半透明で地図の文字が透ける | 不透明の面+赤い文字と枠 |
| 航行設定シートの×がスクロールで消える | つまみと×をスクロールの外に固定 |
| 12px未満の文字が約30か所 | 12pxへ(グラフの軸だけ11px) |

## 6. 決めてほしいこと

1. **出艇前の `航行スタート` を押したら、シートを開かずに前回の設定で始めてよいか。**
   ボタンに名前・艇種・座席を書くので別人の設定には気づける。変えたいときは `設定を変えて開始`。
2. **記録画面のレート(SR)の色を、橙から青に変えてよいか。**
3. **短い記録(1分未満・100m未満)を畳む基準はこれでよいか。**
