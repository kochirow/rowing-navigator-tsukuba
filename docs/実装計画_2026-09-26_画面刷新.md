## 方針

- **1画面(1テーマ)= 1PR。** 各PRは単独で動き、mainへ入れても壊れない。
- **安全判定・警告候補・音の鳴り方・しきい値は変えない。** 変えるのは表示と操作だけ。
  警告の縁の点滅は、既存の `SafetySnapshot.audioDirective` と `ThreatInfo.relativeBearingDegrees` を読むだけ。
- **テストは必要最小限。** 新しく作る純Dartの計算(漕いでいる時間、縁の位置)に単体テストを付ける。
  既存テストは、文言・色・寸法を意図して変えた所だけ直す。全体の `flutter test` と `dart analyze lib test tool` は毎PR通す。
- 見た目の確認は試作と並べて行う。シミュレータのビルドはこの環境で失敗するため(P0 の記録)、**各PRの末尾に実機で見る項目を書く。**
- 順番は **航行中(安全に近く、利用者が最も詰めた所)→ 記録 → その他**。航行中が揃った時点で一度水上で確かめる。

- `HazardPalette`: 航行中の固定危険区域を琥珀の細線+淡い塗りに(監視中・明るい地図は現行のまま)。

- 実機で見る: 暗い地図で川が分かること、他艇(赤)・自艇(白)・橋(琥珀)が浮くこと、ステータスバーが読めること。

## PR-C 航行中: 計器(ドラム式・リセット)

- 新規 `lib/services/rowing_time_accumulator.dart`(純Dart・表示専用): 推定速度が
  `AlertPresentationConfig.stableStopExitSpeedMetersPerSecond` 以上の間だけ dt を積む。測位の欠測中は積まない。
- 新規 `lib/services/lap_counter.dart`(純Dart・表示専用): 練習全体の 距離・chrono・count と、リセット時点の値を持ち、
  「リセットからの値」を返す。count は `RowingMotionFusion` の1本ごとの結果(`distancePerStrokeMeters` が届いた回数)で数える。
  **単体テスト1本**(漕ぐ→止まる→漕ぐ の chrono、リセット後に0から、元に戻す)。**セッションの記録には影響しない**。
- `lib/hooks/use_navigator.dart`: 上の値を読み取り専用の `ValueNotifier` で公開(安全経路には渡さない)。
- `nav_status_card.dart`: 1段目 ペース76・レート70。2段目は左右2つのドラム(`PageView` 縦・スナップ)で
  距離(m)・chrono・DPS・count を切り替え。既定 左=距離・右=chrono。選んだ位置は `SharedPreferences` に残す。
  値は `FittedBox(fit: BoxFit.scaleDown)`、単位は各枠の右下。カードの右下の端に「RESET」ボタン、押したら SnackBar に「元に戻す」。
- テスト: `widget_test.dart` の経過時間の書式(`0:00`)の検証を chrono に合わせて直す。長い値ではみ出さないことを1本。
- 実機で見る: 濡れた指でドラムが回せるか、誤って回らないか、直射日光での読みやすさ。

## PR-D 航行中: 警告の縁の点滅

- 新規 `lib/features/home_map/widgets/edge_alert_overlay.dart`:
  - 入力: 音声チャンネルの対象(`SafetySnapshot.audioDirective`)の種別・`relativeBearingDegrees`・方位の信頼性。
  - **出す条件: 衝突の音が鳴っているとき(他艇・橋・橋脚・流木・中洲・杭)。** カーブ・逆走・表示のみ・system fault・停止中の固定障害物抑制中は出さない。
  - 方角あり: 画面角 = 180 + 相対方位(地図は進行方位+180度)。自艇(横中央・上から45%)からの線が画面の縁に当たる所を中心に、太さ10・長さ280の帯+半径130の光。
  - 方角なし(不変条件10): 縁全体の帯。
  - 1Hz で点滅。`IgnorePointer`。
- 新規の純Dart関数 `edgeAnchorFor(screenAngle, size, selfPoint)`: **単体テスト1本**(右後ろ→右の縁、真後ろ→下の縁)。
- `SafetyBanner`: 画面上の大きなバナーをやめ、読み上げ(`Semantics(liveRegion: true)`)用の見えない要素だけ残す。
  `widget_test.dart` の文字サイズ(`橋` 22px)・`×3` の検証は、見えない読み上げ文言の検証に置き換える。
- 警告の相手の強調: 他艇は白い太縁のマーカー(キャッシュ済みの2枚を1秒ごとに切り替えて点滅)、障害物はポリゴンの線を太く。
- 実機で見る: 艇に固定した状態で縁の点滅が邪魔にならないか、方角が合っているか(右後ろの艇で右の縁)。

## 残り(次にやること)

- **警告の相手の艇の強調**(白い太縁+点滅): 警告・警告候補に相手の艇IDが無い。安全判定側から表示へ艇IDを渡す配線が要る(判定は変えない)。
- **ワークアウトを記録に残す**: 各本の開始・終了を `Session` に保存し、記録画面のセットに使う。航行設定シートにも「ワークアウト」の行。合図の音(警告が鳴っていないときだけの短い音)。
- **出航前チェック**: 音量・GPSの精度は航行中にしか測っていないため見送った。出艇前に測れるようにしてから(分からないものを「良好」と見せない)。
- **当たり判定の断面図**(試作 ④)。
- 記録画面のレート(SR)の色は橙のまま(航行中には指標の色が無くなったため)。
