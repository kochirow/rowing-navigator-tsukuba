# Rowing Navigator サポート

## 問い合わせ

アプリに関する問い合わせ、削除依頼、不具合報告は、次の方法で受け付けます。

- メール：[公開前に問い合わせ先メールアドレスを入力]
- 問い合わせフォーム：[Googleフォームの公開URLを入力]

返信までの目安：[例：原則3営業日以内]

## アカウント・データの削除

アプリ内の「プライバシーとデータ」画面から「アカウントとデータを削除」を選択してください。

この操作により、Firebase匿名アカウント、チーム所属、航行中の共有位置、自分が作成した臨時危険区域、端末内の練習記録および設定を削除します。

アプリを起動できない場合は、メールまたは問い合わせフォームから削除を依頼してください。

## 端末を紛失した場合

端末を紛失した場合は、速やかに問い合わせ窓口へ連絡してください。

チーム名、表示名、最終利用時刻だけでは匿名アカウントを一意に特定できないため、公開前にアプリ内へ削除依頼用参照番号を表示し、その番号を記載してもらう運用を実装してください。招待コード、パスワード、APIキーは送らないでください。

## 招待コードが漏れた場合

招待コードが外部に漏れた場合は、速やかに問い合わせ窓口へ連絡してください。

必要に応じて、現在のチームを使用停止にし、新しいチームを作成して新しい招待コードを発行します。

## 危険区域の訂正・削除依頼

誤った危険区域、位置がずれた固定流木、不要になった臨時危険区域を見つけた場合は、アプリ内で修正・削除するか、問い合わせ窓口へ連絡してください。

問い合わせ時は、次の情報を記載してください。

- チーム名
- 危険区域のおおよその場所
- 問題の内容
- 修正または削除を希望する理由

招待コード、パスワード、APIキーは記載しないでください。

## 注意事項

本アプリは、航行上の安全確認を補助するものです。衝突回避や事故防止を保証するものではありません。

GPS誤差、通信障害、端末の電池切れ、OSの制限などにより、位置表示や警告が遅れる場合があります。
