# Rowing Navigator データ取扱い台帳

更新日: 2026-07-20  
根拠: 現行アプリコード、`database.rules.json`、`firestore.rules`

## 結論

本アプリは、広告、行動ターゲティング、Firebase Analytics、Crashlyticsをアプリ機能として有効化していない。一方、航行中は安全機能のため、正確な位置情報と艇の状態をFirebaseへ送信し、招待コードで参加した同一チームの利用端末だけと共有する。Google Maps/Firebase SDKが宣言する診断・識別情報は、最終ArchiveのPrivacy ReportとGoogleのData safety開示ガイドを基準に別途申告する。

ストア回答では「位置情報を収集しない」と回答してはいけない。位置情報は匿名IDに結び付くため、Google Play Data safetyとApple App Privacyの対象として申告する。

## サーバーへ送信するデータ

| データ | 具体的内容 | 保存先 | 目的 | 保持・削除 |
|---|---|---|---|---|
| 匿名認証ID | Firebase Authenticationが発行するUID | Firebase Authentication | 艇の識別、書込権限 | アプリ内のアカウント削除または管理者による削除まで |
| チーム情報 | チーム名、固定招待コード、所属UID、参加時刻 | Firestore `teams` / `users` / `invite_codes`、RTDB所属bridge | チーム内だけの共有と認可 | 所属とUIDはアカウント削除時に削除。チームと固定コードは他メンバーの利用継続のため保持 |
| 入力した名前・艇種 | 航行開始前に利用者が入力する20文字以内の名前（ニックネーム可）と艇種 | Realtime Database `teams/{teamId}/boat_profiles/{uid}` | 地図と監視一覧で艇を識別 | 航行終了時または接続切断時に削除 |
| 正確な位置情報 | 緯度、経度、GPS精度 | Realtime Database `teams/{teamId}/live_positions/{uid}` | 同チームの他艇表示、接近警告、監視 | 航行終了時または接続切断時に削除 |
| 航行状態 | 進行方向、速度、計測時刻、セッションID、連番 | Realtime Database `teams/{teamId}/live_positions/{uid}` | 接近予測、データ鮮度判定 | 航行終了時または接続切断時に削除 |
| 端末状態 | 電池残量、course/speed精度、protocol/app/profile version | 上記2つのRTDB team path | 監視、安全判定、互換性確認 | 航行終了時または接続切断時に削除 |
| 臨時危険区域 | 中心座標、外周、半径、作成・更新時刻、作成・更新した匿名UID | Firestore `teams/{teamId}/temporary_obstacles` | チーム内で工事等の危険区域を共同編集 | チームメンバーが手動で削除するまで保持 |
| 固定流木の更新 | 中心座標、長さ・幅、回転、余白、revision、更新した匿名UID、直前状態 | Firestore `teams/{teamId}/managed_hazards` | チーム内の固定流木位置の共同更新と誤更新復旧 | チームの安全情報として保持 |

## 端末内だけに保存するデータ

| データ | 具体的内容 | 目的 | 削除方法 |
|---|---|---|---|
| 練習記録 | 時刻、緯度、経度、速度、方位、ストロークレート、警告状態、艇種、シート位置、距離、スプリット | 練習履歴の表示・GPX/CSV出力 | 記録一覧、アカウントとデータの削除、またはアプリ削除 |
| 設定値 | 警告予測秒数、危険区域幅、固定流木キャッシュ | 次回起動時の設定復元とオフライン表示 | アカウントとデータの削除、アプリデータ消去、またはアプリ削除 |
| 一時出力 | 利用者が作成したGPX/CSV | 共有シートへの受渡し | OSの一時ファイル管理、共有先側の削除操作 |

## 収集していないデータ

- メールアドレス、電話番号、住所
- 写真、動画、マイク音声、連絡先、カレンダー
- 広告IDと広告操作履歴
- 決済情報
- Firebase Analyticsイベント
- Crashlyticsクラッシュレポート

## 第三者サービス

| サービス | 用途 | 送信され得る情報 |
|---|---|---|
| Google Firebase Authentication | 匿名認証 | 匿名UID、技術的接続情報 |
| Firebase Realtime Database | チーム所属と航行中の位置共有 | チーム所属bridge、上表の入力した名前・位置・航行・端末状態 |
| Cloud Firestore | 危険区域の共同編集 | 危険区域座標、匿名UID、更新時刻 |
| Firebase App Check | 非正規アプリによる不正利用抑止 | Play Integrity / App Attest / DeviceCheckのattestationに必要な端末・アプリ情報 |
| Google Maps Platform | 地図表示 | Maps SDKのPrivacy Manifestが宣言するDevice ID、Crash Data、Performance Data、Product Interaction、User ID等を含む技術的情報。最終Archiveで確定する |

## ストア申告の回答案

### Google Play Data safety

- Personal info → Name: **収集する / アプリ機能 / 航行中に他の利用端末へ共有 / 削除可能**
- Location → Precise location: **収集する / アプリ機能 / 一時的処理ではない / 暗号化通信あり**
- Health and fitness → Activity and fitness: 距離、速度、ストロークレートの該当性をConsoleの最新設問で確認する
- User-generated content: 利用者が作成する危険区域の名称・形状を申告する
- App activity / App info and performance / Device or other IDs: アプリ本体だけでなく、Google Maps/Firebase SDKの最新開示ガイドに合わせて確認する
- Data sharing: 航行中の位置情報はアプリの中心機能として他の利用端末へ表示する。最新の「sharing」の定義と例外説明をConsole上で確認して回答する
- Data deletion request: アプリ内削除を用意済み。公開Webページにも削除案内と問い合わせ窓口を載せる

### Apple App Privacy

- Contact Info → Name: **収集あり**
- NameのPurpose: App Functionality / Linked to User: **Yes** / Used for Tracking: **No**
- Location → Precise Location: **収集あり**
- Purpose: App Functionality
- Linked to User: 匿名UIDに紐づくため、保守的に **Yes** とする
- Used for Tracking: **No**
- Identifiers → User ID、Fitness、User Content、Diagnostics等: アプリ本体とSDKの最終Privacy Reportで回答する
- Advertising / Third-Party Advertising / Tracking: **No**

## 公開前に人が確認する項目

- [ ] 公開版の`firestore.rules`を反映し、旧`messages`／`static_obstacles`が拒否されることを確認する
- [ ] Firebase Consoleに不要な旧位置データ・旧危険区域が残っていないか確認する
- [ ] プライバシー問い合わせ用メールアドレスを決める
- [ ] 公開するプライバシーポリシーURLを決める
- [ ] 本番FirebaseへApp CheckとSpark quota/使用量監視を設定する
- [ ] 2チームの実端末で、Rulesが他チームの位置・危険区域を拒否することを確認する
- [ ] 12台・2時間の実測でRTDB download 200MB以下/練習、月換算6GB以下であることを確認する

チーム招待制とチーム別pathは実装済みで、Rules Emulator 13件に合格済み。一般公開前に、異なる2チームの実端末とApp Check強制後の配布版で実動作を確定する。詳細は[チーム招待制・無料枠・省電力設計](../design_notes/2026-07-20_チーム招待制・無料枠・省電力設計.md)を参照する。
