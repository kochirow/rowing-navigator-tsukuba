## 6. 12台・無料枠実測

練習前後でFirebase ConsoleのRTDB download/storage、Firestore read/writeを記録する。通常の安全運用と救助体制を維持する。

| 指標 | 開始前 | 終了後 | 増分 | 合格基準 |
|---|---:|---:|---:|---|
| RTDB download | | | | 1練習200MB以下、月換算6GB以下 |
| RTDB storage | | | | 不要なlive/profile残留なし |
| Firestore reads | | | | 無限listener/異常増加なし |
| Firestore writes | | | | 危険区域操作回数と整合 |
| 最悪端末の電池消費 | | | | 団体が承認した基準内 |
| 最大端末温度/体感発熱 | | | | 航行/充電運用を阻害しない |

- [ ] 全状態で2/5/10秒送信が選ばれ、2秒未満のクラウドwriteが発生しない
- [ ] クラウド2秒送信でも端末内1秒警告と地図が滑らか
- [ ] 12台全てで同時接続し、艇のちらつきや大量再接続がない
- [ ] 月10GB上限へprotocol/TLS overhead込みで余裕がある
