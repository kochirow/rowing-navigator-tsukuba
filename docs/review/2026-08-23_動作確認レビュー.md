## 3. 指摘

### S2-01: 逆走音声オフが航行画面では「音あり」と表示される

**症状**

利用者が「逆走注意の音声」をオフにすると、実音声は止まる一方、航行バナーは
単発・断続音が鳴る `action` の濃色表示を保つ。設定シートを閉じると、逆走音声が
静音中であることを示す常設表示もない。

**再現条件（コード上）**

1. 航行中に「メニュー」→「航行中の警告設定」→「逆走注意の音声」をオフにする。
2. `SafetyOrchestrator` は `REVERSE_AUDIO_DISABLED` を付け、
   `audioAsset` と `audioEventId` を `null` にする
   （`lib/services/safety_orchestrator.dart:809-829`）。
3. `NavigationWarningService` は `entryEvent` を無条件に `once` / `action` とし
   （`lib/services/navigation_warning_service.dart:14-23`）、`audioAsset == null` でも
   標準の逆走音声を再補完する（同125〜134行）。
4. `SafetyBanner` は `action` を「単発・断続音」の濃色表示として扱う
   （`lib/features/home_map/widgets/safety_banner.dart:13-19`）。

**影響**

- 実再生は `SafetySnapshot.audioDirective` から直接行うので、UIが補完した音声が
  実際に復活するわけではない。ここは自己反証で確認した。
- しかし画面の「音あり/表示のみ」の意味が実態と逆になる。
- 一度オフにしてシートを閉じたあと、同じ航行の後半で本当に逆走しても無音である。
  漕手は航行中に画面を見続けられないため、静音状態を忘れる条件が重なるとF1へ寄与する。
- 次回航行開始時は `true` へ戻る（`lib/hooks/use_navigator.dart:4037-4039`）ので、
  航行をまたいで静音が残る問題ではない。

**分類**: FN側、S2、証拠は「推定」。実機UIと実音声を同時観測していないため。

**修正の方向**

- UI変換では `candidate.audioAsset == null` をそのまま無音として保持し、
  `audioMode=none`、`urgency=monitoring`（または静音専用の表示状態）へ変換する。
- 航行画面に「逆走音声オフ」を常設表示し、設定シートを開かなくても分かるようにする。
- `SafetyOrchestrator` → `NavigationWarningService` → `SafetyBanner` を通した回帰テストを足す。
  現在の追加テストはオーケストレータ単体までで、UI変換の再補完を検出できない。

- 同じ8+の2台で11回対23回だったため、測位のペア差も確認した。
  最初の60秒を除き、UTC差600ms以内のraw 672組は
  median 2.66m / p95 4.90m / p99 7.52m / max 10.87m、8m超6組、10m超1組。
- 同ログに記録された旧filtered位置は p95 22.93m / p99 30.91m / max 32.34mで、
  旧推定のtailが大きい。現在の本番設定はraw代表点を使うconservative解なので、
  11回対23回を現行1.2.1の端末差とは断定しない。

- 逆走音声切替は1.1.2ログに存在しないため、実機replayでは検証できない。

## 7. 利用者が実機で確認する手順（修正後）

このレビュー時点で実施するConsole設定はない。S2-01と版不一致を直した後、
署名済みテスト版で次を確認する。

1. 端末2台で同じチームへ入り、両方で航行を開始する。
2. 「メニュー」→「航行中の警告設定」→「逆走注意の音声」をオフにする。
3. シートを閉じても、航行画面に「逆走音声オフ」相当の常設表示が残ることを確認する。
4. 逆走条件を安全な試験手順で作り、逆走バナーは出るが音は鳴らないことを確認する。
5. 同じスイッチをオンへ戻し、次の安全評価（通常1秒以内）で逆走音が鳴ることを確認する。
6. 同時に他艇警告を発生させられる場合、逆走オフ中でも他艇音が鳴ることを確認する。
7. 2台の「端末とデータ」で位置共有/他艇受信が利用可能と表示され、相手位置が更新し続けることを確認する。

実機試験は周囲監視を優先し、艇を安全に停止できる場所と担当者を決めて行う。
