## 2. 修正1(S1-03): 初回GPS位置が無くても航行を開始する

### 何が悪いか

航行開始の処理(`lib/hooks/use_navigator.dart` の `startNavigation`)は、最初に
`geoService.getNavigationBootstrapPosition()` で位置を1つ取る。

- 手元に位置が無いと `Geolocator.getCurrentPosition` を15秒待つ。
  取れないと `TimeoutException` が起き、**航行開始が丸ごと中止される**。
- 取れた位置の座標が不正だと `StateError` を投げて、やはり**中止される**。

ところが `startNavigation` には、初回位置が「使えない」ときの逃げ道がすでにある
(`if (initialGpsUsable) { ... } else { gps_bootstrap_unusable を記録 }` の else 側)。
そのあと位置ストリームを開始するので、最初の測位が届けば普通に動く。
**「位置が無い」をこの逃げ道へ流せば直る。**

### 方針

- `getNavigationBootstrapPosition` は**例外を投げず、位置が無ければ `null` を返す**。
- 新しい測位は**待たない**(15秒待ちをやめる)。手元の位置(画面で取得済み・OSの
  last-known)だけを見る。新しい測位は、直後に始まる位置ストリームが届ける。
- `startNavigation` は `null` と「座標が不正」を「初回位置なし」として扱い、開始を続ける。
  GPSは「利用不可」として表示される(既存の仕組みがそうする)。

## 4. 修正3(S2-02): 起動時の設定移行が失敗してもアプリを開く

### 何が悪いか

`lib/main.dart` は `runApp` の前に `SafetyDefaultsMigrationService().migrateIfNeeded()` を
`await` している。これは端末の保存領域(SharedPreferences)を読み書きし、例外を捕まえない。
保存領域が失敗・応答停止すると、**アプリが真っ白のまま開かない**(全機能の喪失)。

移行は「世代番号を最後に書く」ので、途中で失敗しても**次の起動で最初からやり直す**
作りになっている。だから失敗したら諦めて起動を続けてよい。

### 4-1. `lib/services/safety_defaults_migration_service.dart`

**(a) 先頭の import に1行足す。**

```dart
import 'package:flutter/foundation.dart';
```

(既存の `import 'package:shared_preferences/shared_preferences.dart';` の上に置く)

**(b) クラスの定数の並び(`static const _sharedCachePrefix = ...;` の下)に足す。**

```dart
  /// 起動時に移行を待つ上限。端末の保存領域は通常数ミリ秒で応答する。
  /// これを超えて止まるなら、移行を諦めてアプリを開く方を選ぶ(原則1)。
  static const startupTimeout = Duration(seconds: 3);
```

**(c) `migrateIfNeeded()` の上に、新しいメソッドを足す。** `migrateIfNeeded` 自体は変えない。

```dart
  /// 起動時の移行。**失敗しても応答が止まっても、例外を出さずに終わる。**
  ///
  /// 移行が終わらないとアプリが開かず、航行も監視も記録も使えなくなる。
  /// それよりは、端末に残っている値のまま開く方がよい(原則1)。
  /// 世代番号は最後に書くので、失敗した移行は次の起動で最初からやり直す。
  /// 上限を超えた移行は裏で続くことがあるが、書く値はコード既定値だけである。
  Future<void> migrateOnStartup({Duration timeout = startupTimeout}) async {
    try {
      await migrateIfNeeded().timeout(timeout);
    } catch (error) {
      debugPrint('安全設定の既定値への移行を完了できませんでした(起動は続けます): $error');
    }
  }
```
