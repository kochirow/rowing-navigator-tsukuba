## 0. この計画の約束

1. **表示専用の機能である。安全経路には1行も触れない。**
   衝突判定・提示・位置共有・推定器(`lib/hooks/use_navigator.dart`、`lib/services/` の安全経路)は変更しない。
   新しい部品から安全経路の部品を import するのは、読み取り専用の `ChannelCenterline` と
   `SessionAnalyzerService` だけに限る。**逆方向の import は作らない**(PR1 で機械的に検査する)。
2. **1PR = 単独で動く1段階。** どのPRで止めても、アプリは前より悪くならない。
3. **判定・計算は純Dartに置き、単体テストを付ける。** widget の中で数字を計算しない
   (CLAUDE.md「安全判定に関わる純粋ロジックは純Dartへ」と同じ作法を表示にも使う)。
4. **閾値はすべて `lib/config/record_replay_config.dart` に置き、前提を書く**(設計原則7)。
   試作で使った値をそのまま初期値にする。
5. **試作の挙動が正解である。** 迷ったら `tool/prototypes/record_replay/index.html` を開いて同じ操作をし、
   同じ結果になるかで判断する。

### 1.1 2026-09-24 最終フィードバックで確定したこと

- 「ワーク時間」→「漕いでいた時間」、旧「漕いでいた時間」→「練習時間」。
- セットや自分で選んだ区間では、内訳は既定で畳む。グラフへ最短で届くことを優先する。
- 拡大後は左右に移動できる(1本指のなぞり・スクロールバー)。拡大していないときの1本指は従来どおりカーソル移動。
- 各セットの表の横棒をやめ、空いた幅にDPSを足した。

### PR6 操作

- 時間軸: なぞる(カーソル)・タップ(セット→もう一度で本)・長押しなぞり(範囲)・つまみ(端に吸着)。
- 再生: 5段階の速度、区間の終わりで止まる、地図が艇を追う。
- グラフ: タップで本を拡大・「‹ セット全体に戻る」、ピンチ拡大、拡大中の1本指移動とスクロールバー、ダブルタップで戻す、
  指標の切替、横軸[時間|距離]。
  **スクロールとの取り合い**: グラフは縦スクロールの中にあるので、拡大していないときの横なぞりはカーソル、
  縦の動きはページのスクロールに渡す(`HorizontalDragGestureRecognizer` と `ScaleGestureRecognizer`)。
- 畳む欄: 区間の微調整(±1秒・±30秒・再生位置を開始/終了にする・時間で指定)、内訳の行タップ。
- 共有テキスト(LINE向け)。
- テスト: controller の単体テスト(選択・拡大・移動・再生の状態遷移)と、主要な操作の widget テスト。

### PR7 地図の仕上げ・一覧・入口

- 地図: ペースの色分け(本・区間の中だけ)、危険区域・航路の切替(航行画面と同じ描画データと
  `map_layer_spec.dart`・`hazard_palette.dart` の色)、衛星写真、暗いテーマのスタイル。
- 一覧: カードにセットの要約(例「UT 33:14 ・ ハイレート 5本」)。記録の要約を別ファイルに持つ索引を足し、
  一覧で全航跡を読まないようにする(旧記録は初回に作る)。
- 入口は PR5 で対応済み(§6-1)。
- テスト: 索引の作成・再作成、旧記録の読み込み。

### PR8 実機での確認と調整

実機(iPhone・Android)で次を確かめ、結果を `docs/review/` に残す。コードの調整はこのPRで行う。

## 5. 危険と手当て

| 危険 | 手当て |
| --- | --- |
| 地図の艇アイコンが、なぞる速さに追いつかない | PR5 の実機確認で方式を決める。どちらでも更新を1秒15回程度に間引き、指を離したら正確な位置に置き直す |
| 2時間の記録で解析が重い | 解析は画面を開いたときに1回だけ。100msを超えたら `compute` で別 isolate へ。再生中・操作中は再計算しない |
| グラフの操作とページのスクロールが取り合う | 拡大していないときの縦の動きはページへ渡す。実機で確認(PR6・PR8) |

| 監視端末で2つ目の地図を開き、監視が重くなる | PR8 で確認。問題があれば、監視中は記録画面の地図を簡易表示(航跡の線だけ)に落とす |

| 試作とアプリで結果が食い違う | PR2・PR3 のローカル検証ツールで、同じログに対して数字を突き合わせる |

## 6. 利用者の決定(2026-09-24)

1. **記録画面の入口:** 航行していないときは航行モードでも開ける。航行中は今どおり出さない(PR5 で入れる)。
2. **「補正前と比べる」:** アプリには入れない(利用者「補正前を見たい場面はない」)。
   推定の中身は「タイムの推定に使った記録」の欄で確かめられるので、それで足りる。試作には残す。
3. **ハイレートのセットをまとめる間隔:** 5分のまま。
