# Rowing Navigator

## 概要

Rowing Navigator はローイングの安全な航行を支援するアプリです。
艇の航行状況や危険な水域をマップ上にリアルタイムに可視化、他艇や危険な水域への接近を検知して音声による衝突警告を行います。

本アプリは、Shunsuke Oba の修士研究において開発されました。修士論文は[こちら](https://github.com/obashun22/master_thesis)からご覧いただけます。

## 起動方法

アプリを起動する前に API Key と Firebase のセットアップが必要です。

```bash
$ flutter pub get
$ flutter run
```

## 使い方

### 水域の状況を確認する

アプリを起動すると水域マップが表示され、水域の状況（静的障害物および航行中の他艇）を確認することができます。静的障害物は、水域マップ編集機能を使用して登録することができます。航行中の他艇は、Rowing Navigator が起動され、ナビゲーションモードがオンになっている端末が表示されます。  
また、水域マップ表示切替機能を使用して、通常地図と航空写真を切り替えることができます。  
本機能は、乗艇時以外でも使用することができます。

### 衝突警告を行う

乗艇中に衝突警告を行うには、水域マップ画面下の「Start Nav」からナビゲーションモードをオンにします。ナビゲーションモードでは、自艇が他艇または静的障害物と衝突することが予測される場合に音声による警告を行います。衝突予測は自艇および他艇の艇速を考慮して行われます。衝突警告の詳細については[設計書](./docs/DESIGN.md)を参照してください。  
また、ナビゲーションモードでは自艇の航行情報が他の端末と共有され、水域マップ上に自艇の情報が表示されます。  
本機能は、乗艇時の使用を想定しています。

⚠️ 警告は音声で行われるため、端末の音量は中程度に設定してください  
⚠️ 低速時の艇の針路として端末の地磁気情報を使用するため、乗艇の際には端末上部を進行方向に正確に向けて設置してください

### 水域マップを編集する

水域マップ編集機能を使用して、水域マップ上に静的障害物を登録することができます。静的障害物を登録するには、水域マップ画面右側のマップアイコンから水域マップ編集画面に移動します。  
水域マップ編集画面では、プラスアイコンを押した後、静的障害物の領域を囲い描くことで静的障害物を登録することができます。登録した静的障害物は、水域マップ上に赤い領域として表示されます。静的障害物を削除する場合は、領域をタップすることで削除することができます。

## 現在の課題

| 課題                                                       | 概要                                                                                                                               |
| ---------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| バッテリー消費量の低減                                     | 位置情報取得や通信によるバッテリー消費が大きいため、最適化が必要                                                                   |
| 測位誤差の低減                                             | スマートフォンの GPS 精度に依存しており、誤差が発生する                                                                            |
| 欠落したセンサ値の補完                                     | 位置情報が断続的に欠落する場合があり、補完手法の検討が必要                                                                         |
| 端末の設置方向の改善                                       | 現在は端末を艇の針路方向に向ける必要があるため漕手にとって見ずらく改善が必要                                                       |
| 端末の設置方法の改善                                       | 現在は低速時の艇の針路として端末の地磁気情報を使用しているが、乗艇中に端末の設置方向がずれるため、より安定した設置方法の検討が必要 |
| 高頻度通信によるサーバ負荷の軽減                           | 頻繁なデータ送信がサーバ負荷増大につながるため、最適化が必要                                                                       |
| コスト面から高頻度通信に適したインフラサービスへの乗り換え | サーバコスト削減のため、より適したインフラの検討が必要                                                                             |
| 場所を変えても動作するかの検証                             | GPS 精度や地理計算について国外での動作検証が未実施                                                                                 |
| 近隣の艇情報のみ取得                                       | アプリの負荷低減のため水域周辺の艇情報のみを取得・表示する仕組みの実装が必要                                                       |
