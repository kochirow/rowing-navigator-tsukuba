# Rowing Navigator

## 概要

Rowing Navigator はローイングの安全な航行を支援するアプリです。
艇の航行状況や危険な水域をマップ上でリアルタイムに可視化するとともに、他艇や危険な水域への接近を検知して音声による衝突警告を行います。
